# Web application vulnerabilities
SQL injection occurs when untrusted input is concatenated into a database query. Prevent it with parameterised queries and least-privilege database accounts.
Cross-site scripting (XSS) injects scripts into pages viewed by other users. Prevent it with output encoding and a Content Security Policy.
The OWASP Top 10 lists the most critical web risks, including broken access control, cryptographic failures and injection.
